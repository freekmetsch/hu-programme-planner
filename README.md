# HU programme planner

[Open the programme planner](https://freekmetsch.github.io/hu-programme-planner/)

Explore courses, teaching periods, and the 2026–27 weekly calendar for six English and Spanish teacher education programmes. Use the top switch to choose Programme planner or Academic year overview. Programme planner contains Programme, Periods, and Courses.

Academic year overview lists all 53 weeks. Green marks study weeks and breaks. Red marks test weeks. Purple marks resit weeks. All resit weeks have equal emphasis. Assessment weeks are not shown. You can print the overview on one A4 landscape page.

Check a course when it is finished or exempt. The planner counts credits for the propedeutic and main phases. Matching course codes share one mark. Teaching options stay within English or Spanish.

Marks and filters stay in this browser. They do not change Osiris. The site has no account or analytics. Clearing browser data removes saved marks.

Use the [HU study guides](https://studiegids.hu.nl/) for official programme information. Each course detail links to the selected programme's 2026–27 guide. Check course and test entry requirements there before planning ahead.

Open `index.html` in a browser. The `sources` folder preserves the transcribed course tables, year calendar, registration text, and course transcription.
