# HU programme planner

[Open the programme planner](https://freekmetsch.github.io/hu-programme-planner/)

Compare courses and teaching periods for the 2026–27 English and Spanish teacher education programmes. Use Programme, Periods, or Courses to explore all six fulltime and parttime routes.

The same course code means an equivalent course across programmes. Teaching periods can differ. Dates and registration limits remain available in the planner.

Open `index.html` in a browser. The site has no server, account, or analytics. Selections stay in the browser.

The `sources` folder contains the supplied course tables, year calendar, registration text, and course transcription.
